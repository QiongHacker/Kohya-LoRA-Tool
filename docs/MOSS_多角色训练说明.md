# MOSS 多角色 LoRA

2026-10-20，源码功能说明。前端构建和 Python 语法检查通过；尚未进行本轮多角色 GPU 训练和画质验收，也未发布安装包。

## 入口

新建项目 → **MOSS-Image / MOSS-Image Base** → **多角色（实验性）** → Fizgig v8.5.0。

训练使用 Base，默认采样使用 SFT；已有模型与组件选择继续生效。多角色流程从新任务开始，不自动使用旧快照。

## 素材与身份

1. 每个角色建立一个单人目录，设置名称、独立触发词和角色描述。可配置两个、三个或更多角色。
2. 同框图片另建目录，选择其中实际出现的角色。每张图的同名 `.txt` 应分别说明触发词、外观、位置、服装和动作。
3. 无逐图标签时使用角色描述与同框组的位置、场景模板。模板只适合同组所有图片确实符合描述的情况；动作或站位不同请分组或补逐图标签。
4. 检查原图和标签，确认同框组身份与位置一致，再点击「检查素材与标签」。

例如，单人标签：

```text
zwxem, a woman with shoulder-length blue hair, wearing a red jacket, looking toward the camera in a cafe
```

同框标签：

```text
Two women are talking at a cafe table. On the left is zwxem, with shoulder-length blue hair and a red jacket, leaning forward. On the right is knurv, with black hair in a low bun and a white shirt, holding a cup.
```

触发词保持用户输入，不自动拼接类别或改名。已有逐图标签保留正文；单人图缺少自己的触发词时会补上。单人标签含其他已配置角色、同框标签遗漏已指定角色时会阻止训练。预处理保留完整构图，均衡采样对少样本角色最多复制到 3 倍。

单人素材学习各自身份；同框素材用于学习身份在同一画面内的归属关系。只有单人素材仍允许开始，但同框效果必须另行检查。

## MOSS 同框验证

- 按勾选顺序设置目标组合，也可从同框组添加组合。
- 未填组合时按同框组派生；没有同框组时生成双人及全角色组合。
- 默认生成单人、同框和角色换位提示词。同框使用 MOSS 的原生 JSON 布局，每个区域分别写入触发词与角色描述。
- 可关闭「使用 MOSS 原生布局验证」，改用自然语言。自填提示词按原文使用，须包含所选角色的触发词；允许粘贴一整段格式化 JSON。
- 训练中自动预览最多 6 条，优先覆盖多人组合，并保留单人对照；完整提示词全部导出。
- 低显存自动档可能关闭训练中采样，需手动开启；采样关闭时仍导出提示词。

输出目录中的文件：

| 文件 | 用途 |
| --- | --- |
| 多角色验证提示词.txt | 完整验证提示词，段落之间为空行 |
| MOSS_多角色验证.jsonl | 每行一个验证案例，包含角色、提示词、宽高 |
| 多角色使用说明.txt | 触发词、使用方法和本次素材提醒 |

JSON 使用官方 `summary.caption`、`items`、`bbox_coord_space=abs_centralized`、`bbox_format=yxyx`。坐标按本次采样分辨率生成。在出图工具中保持相同宽高，把 `prompt` 的完整内容作为正向提示词。改变尺寸时需要重新生成或调整坐标。

布局控制用于验证生成，训练图片仍使用其真实描述；这不是局部重绘，也不会自动给训练图片识别人脸或标注框。全局正向词合入 JSON 的场景描述，不拼接到 JSON 外侧。

## 可选：DOP 角色泄漏约束

默认关闭。开启后每 2 步做一次 DOP，权重 2；每个角色可选择 person、woman、man、girl 或 boy 作为不含身份的通用类别。额外分支把触发词替换为类别，约束 LoRA 保持原底模的预测，训练日志记录实际开关和触发词。

会增加文本编码缓存和训练耗时。开启时另导出一条不含角色触发词的对照提示词，检查普通人物是否仍保持原底模表现。

**这只接入 DOP 分支。** 不包含上游完整 LoRA Isolation 的陌生人拼图增强、样本学习率加倍和触发词拼接。上游完整方法的量化评估在 Krea 2 上进行，不能直接当作 MOSS 的效果证明。

## 本地开始训练

沿用 MOSS 现有默认参数：512 分辨率、Rank/Alpha 16/16、学习率 1e-4、BS 1、自动精度。首次可先用较少轮数确认数据和采样，再依据中间检查点决定训练量；不要用 Loss 单独判断拟合程度。

首先准备两个角色及一个同框组，检查：单人是否分别正确、同框人数是否正确、服装与发型是否串到另一个人、互换站位后身份是否保持。确认后再增加第三个角色和更多组合。DOP 开关的效果需要在相同素材、参数、提示词和种子下对比。
