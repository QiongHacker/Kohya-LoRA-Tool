# Anima 28 层结构与社区分层研究

核对日期：2026-10-18。范围：标准 Anima 2B，DiT blocks 0–27。

## 结论

公开代码足以核对网络结构；社区已有覆盖 28 层的合并经验表、分层权重工具和特定干预下的逐块实验。此次没有找到足以将每层定义成固定语义职责、并验证其跨底模和跨任务普适性的完整证据。应区分结构事实、特定操作的实验结果和合并作者的经验。

## 可以从代码确定的内容

- 标准模型具有 28 个 DiT 块。每块包含自注意力、交叉注意力、MLP 和 AdaLN 调制。各块结构相同，但参数不同。[1][2][3]
- 常规前向按顺序运行各块，之后才进入 final_layer。块编号不是扩散采样步数；一次网络前向会依次经过这些块。[1]
- 自注意力处理图像特征位置间的关系；交叉注意力让图像特征读取文本条件；MLP 做逐 token 非线性变换；AdaLN 根据时间步调制各子层。[1]
- Anima 另有 LLMAdapter；其内部块不能与 DiT 的 28 块混为一谈。官方微调建议冻结这个文本适配器，使用 Base 训练 LoRA。[2][4]

## 社区已经做了什么

### Crody 的合并经验

Crody 的原文列出 L00–L27，并展示自己的 Nova 模型合并配方；以下仅压缩其经验分区，不代表官方功能定义。[5]

| 范围 | 作者观察的主要影响 |
|---|---|
| L00–L03 | 局部细节、线条、背景及身体结构入口 |
| L04–L08 | 服装、身体比例、肢体与姿态 |
| L09–L13 | 构图衔接、脸部轮廓与基础形状 |
| L14–L17 | 眼区、表情、脸部与年龄观感 |
| L18–L21 | 鼻口、下颌、下半脸与表情 |
| L22–L24 | 材质、光影、背景细节与上色 |
| L25–L27 | 最终画风、颜色与对比度 |

这张表应作为实验候选区间使用。原文的操作是模型或 LoRA 合并，也继续细分 attention、MLP、norm 等模块；不能把某层等同于一个独立器官开关，更不能直接将合并效果外推为从头训练 LoRA 的最优层选择。[5]

### sorryhyun 的调制实验

作者在 Modulation Guidance 文档中报告：其干预下 blocks 0–7 对粗布局、整体色调较敏感，block 27 有补偿作用。因此其特定引导预设避开这些块。这为“层的影响取决于修改方式”提供了一个具体例子；它没有证明这些层只承担该功能，也不是普通 LoRA 训练层选择的通用结论。[6]

### 分层工具

Animerge 提供分层合并、组件权重、分析和训练界面。工具能按块操作，并不等于已完成各块语义的因果解释。它也区分 Base 28 块、2.9B 40 块和 3.8B 52 块，扩展版不能直接套用同一索引。[3]

## 对训练软件的判断

建议将层号、模块和实验对照明确显示。经验层组可以作为高级实验预设，但不应命名为确定的“眼睛专用层”或“只学脸、不学画风”。若要验证训练预设，应固定底模、数据、训练预算和采样条件，比较全层基线与候选层组，再用未参与训练的提示词和多个种子检查目标变化和副作用。本次未执行训练或出图实验。
